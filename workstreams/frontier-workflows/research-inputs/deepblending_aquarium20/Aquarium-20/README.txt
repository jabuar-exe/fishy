Contents
========
The dataset contains the original camera images without any processing
(e.g. undistortion). Camera matrices computed using Noah Snavely's Bundler
software are contained in bundle.out. A reconstructed produced by
Yasutaka Furukawa's PMVS package and mesh reconstructed using Misha
Kazhdan's Poisson surface reconstruction are also provided.

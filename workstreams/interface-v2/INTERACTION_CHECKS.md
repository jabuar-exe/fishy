## Integration gotchas

- Treat a continuous slider interaction as a transaction: capture a pre-gesture scene on start, render intermediate values without appending history, and commit at most one final scene on completion. Keyboard range changes need an equivalent grouping rule.
- The preset action must calculate/validate the entire candidate scene before setting any UI state. Do not update dimensions one axis at a time, especially when a protected object blocks fitting.
- Keep selection by object ID, never array index or display name. Material Apply must patch the selected record; it must not replace the record or regenerate its ID.
- A focused exact input is a pending transaction. Save/export must deliberately resolve valid input once or halt on invalid input; blur side effects must not create a duplicate history entry.
- Ensure the mobile sheet’s close path restores focus to the trigger and cancels any active transform/control transaction before it unmounts.
